# Fuentes locales de Kánna

Son las mismas familias y pesos que utilizaba `app/layout.tsx` con `next/font/google`.
Se conservan localmente para compilar sin acceder a Google Fonts. `next/font/local` genera
los recursos que sirve la aplicación; no se llama a un proveedor de fuentes desde el navegador.

Fuentes originales del repositorio oficial [google/fonts](https://github.com/google/fonts):

- [Atkinson Hyperlegible](https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegible): regular y negrita.
- [Bricolage Grotesque](https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque): variable, pesos 600–800.
- [Geist](https://github.com/google/fonts/tree/main/ofl/geist): variable, pesos 400–600.
- [Instrument Serif](https://github.com/google/fonts/tree/main/ofl/instrumentserif): cursiva, peso 400.

Descargadas el 3 de noviembre de 2026. Cada carpeta conserva su licencia `OFL.txt`.
No se modificó el contenido de los archivos tipográficos.
